# Documented baseline — 2026-08-11

Successor to `docs/reports/naive-first-run.md` §"Baseline before Run B"
and the workspace section of `handbuilt-first-run.md`. This is the
canonical description of the workspace at the start of any exam or
sweep from 2026-08-11 onward.

**How this baseline is verified.** Workspace-wide, not team-scoped.
The 1.8 grader fix moved every non-write query off `team:...` because
teamless stories exist and must be visible; the same rule now applies
to `checkBaseline` and `snapshotIdSet` in `packages/harness/src/
baseline.ts`. The canonical inventory query is
`GET /search/stories?query=is%3Astory&page_size=100`; the count must be
exactly ten, and every id must appear in the table below with the
listed fields.

## What "clean" means for the harness

At the start of an attempt, `checkBaseline` must confirm:
1. Workspace-wide story count = 10.
2. Every id in the table above is present with the listed
   `workflow_state_id`, `epic_id`, `story_type`, and `group_id`.
3. No story exists whose id is not in the table.

Teardown must fetch the same workspace-wide snapshot, delete any
strays created during the attempt (regardless of team), and re-verify
the same conditions before the next attempt begins.
